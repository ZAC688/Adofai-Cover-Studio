# 本机验收素材

Git 保存样本清单、人工标注、向量草稿和测试代码；`reference/` 中的用户原始截图及其派生图片保留在本机，不纳入提交。项目根目录的 `testscreenshots/` 和 `Thumbnail/` 同样忽略。忽略规则不会删除本机文件。

当前工作区的素材与测试保持原样可用。若在另一份检出中运行依赖真实截图的测试，需先按 `manifest.json` 恢复对应素材文件；缺少素材或识别不达标时应如实失败，不跳过测试或降低验收标准。

人工确认过的参考标注在 `annotations/`，与原图尺寸对应；`annotation-drafts/` 保存标注来源和草稿。透明功能素材由已确认标注与对应原图组合生成，不作为独立的识别泛化样本。
