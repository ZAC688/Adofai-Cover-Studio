# 0.6.0 开发与验收

用户确认：滤镜预设包含参数、开关、顺序和局部范围／所需贴图；应用替换当前目标且可撤销。作者显示 ZAC688。逐项有效测试通过后分别提交，最后独立打包和执行所有测试。用户的 `discription.docx` 及根目录原始 `fonts/` 不加入提交。

1. 滤镜预设本机保存、导出、导入和应用。
2. 进入滤镜及切换对象默认折叠全部详情。
3. Delete 删除对象，保护输入和底图。
4. 上传入口移到顶部，扩大对象列表。
5. 顶部信息窗口显示作者、版本、日志和离线说明。
6. 新等级分类 P 开头优先、crazy 末尾。

## 第 1 项

本机 SQLite 保存独立、自包含的预设。导出 JSON 包含所需 PNG 及校验值，导入完整校验后保存；只在应用时物化素材，当前目标替换纳入一次撤销，其他对象及共用滤镜保留。预设文件上限 100 MB；损坏文件提示错误，保留原作品和预设。

前端 37 项、构建通过；12 项后端及真实浏览器测试通过（19.50 秒），覆盖全部 38 种参数、源与全新数据目录间蒙版／贴图逐字节往返、两画幅范围、保存重开、错误文件及失败保护、应用撤销和最终 PNG 严格逐像素一致。证据：`artifacts/upgrade-06/01-presets/tests.xml`。

## 第 2 项

已有滤镜进入栏目、切换对象和手动切换管理范围时默认折叠详情，列表标题仍可见。新添加的滤镜展开便于立即调节；应用预设产生的新条目默认折叠。展开／折叠不写入作品，不改变画面。

构建通过；新增默认折叠与既有管理、精细滑块、预设回归共 6 项通过（45.53 秒）。原测试在刷新后需操作详情时补充展开动作，其余数值、存储及像素标准保留。证据：`artifacts/upgrade-06/02-fold/tests.xml`。

## 第 3 项

Delete 删除当前标题、轨道或贴纸，复用原撤销和本机保存；底图锁定。输入框、可编辑内容、输入法组合期间和任何模态窗口中不触发；按住按键的自动重复不会连续误删。

构建通过，4 项新增键盘测试和 4 项原多对象回归共 8 项通过（61.72 秒）。覆盖三类对象的删除／撤销／刷新、普通文本 Delete、数值框、contenteditable、弹窗和底图保护。证据：`artifacts/upgrade-06/03-delete/tests.xml`。

## 第 4 项

两个上传按钮移到顶部工具栏，继续使用原始上传与替换流程；对象列表使用左栏剩余高度独立滚动，保持图层拖动排序、对象操作和退出入口。顶部在较窄桌面窗口中压缩间距。

构建通过，6 项顶部布局、实际文件选择器上传、黑白主题和编辑器回归通过（36.71 秒）。在 1440×1000 与 1050×760 验证无顶部横向溢出，对象列表比原上限增加至少 80px；已检查实际截图。证据：`artifacts/upgrade-06/04-layout/tests.xml`、`editor.png`。

## 第 5 项

顶部信息按钮显示作者 ZAC688，版本直接读取前端 package.json（本轮 0.6.0），更新日志和完整使用说明均随前端离线打包。支持分页查看、滚动、Esc、Tab 焦点循环及关闭后返回原按钮；复用同一份使用说明文件。

首次测试发现 Chrome 原生 Ctrl+Z 会越过只读窗口撤销背景文字编辑，已阻止窗口内的原生撤销／重做和 Delete，保留复制与阅读。构建及 lint 通过；信息、顶部与 Delete 共 6 项回归通过（35.38 秒），校验作者／实际版本／说明内容、无外部请求、作品不变和焦点行为。已检查实际截图。证据：`artifacts/upgrade-06/05-info/tests.xml`、`about.png`。

前端 38 项、构建通过；4 项贴纸回归通过（37.69 秒）。实际 62 份顺序为 P1—P20、G1—G20、m21、U1—U20、crazy；检查每个分类完整 ID 集合及组内排序，并实际添加 P10 和 crazy，保留原 GIF、旋转、阴影、排序、导出和无限数量回归。证据：`artifacts/upgrade-06/06-stickers/tests.xml`、`new-levels.png`。
