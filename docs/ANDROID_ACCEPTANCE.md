# OPPO Reno12 安卓测试清单

用户已确认 0.8.1-android.1 在 OPPO Reno12 上完成功能验收。当前 0.8.1-android.2 为 16KB 兼容性更新，以下保留为新版回归清单，尚未逐项记录新版的实机复测结果。Android 与 ColorOS 具体版本仍未提供。

## 安装与显示

- [ ] 用系统文件管理器打开 APK 并安装；启动后显示编辑器，而不是空白或错误页面。
- [ ] 开启飞行模式后冷启动，贴纸、字体、滤镜、识别和谱面生成仍可用。
- [ ] 竖屏、横屏均可看到预览、顶部操作、底部四栏目，页面没有横向溢出。
- [ ] 每个参数区域可滚动到底，信息、贴纸、融合、蒙版和谱面窗口的确认／取消按钮可见。
- [ ] 弹出输入法后能编辑标题与数值，隐藏输入法后布局恢复；刘海、系统手势条不遮挡按钮。

## 完整编辑

- [ ] 上传 PNG/JPEG 底图、透明轨道及截图；单图超过 10 MB 被拒绝，原作品保留。
- [ ] 添加、选择、拖动、缩放、旋转和删除对象；标题与轨道各最多 5 个，贴纸可继续添加。
- [ ] 拖动对象把手排序，撤销／重做正确；快速触摸按钮只执行一次。
- [ ] 切换中英文字体并上传自有字体，中文能正常显示；切换普通／3D 文字产生真实立体效果。
- [ ] 光效模块、渐变跟随、阴影均可调；关闭模块后对应效果消失，折叠不改变画面。
- [ ] 38 个滤镜可添加与调参，对象／画布／局部范围正确；恢复默认、排序、开关和撤销有效。
- [ ] 纯色背景轨道识别得到真实透明结果，取消和重试可用；保留／擦除画笔能修改蒙版。
- [ ] 融合渐变的位置、宽度、角度和反向均改变实际像素，取消不改作品。
- [ ] 从 .adofai 导入，起止选段、点选、裁切、图标和高分辨率预览正常；曲名／作者可选生成白色标题。
- [ ] 253 份贴纸按分类和既定顺序可选，GIF 可选择静态帧，贴纸缩放、旋转和阴影有效。

## 文件与保存

- [ ] 导出封面，系统保存窗口可选 Downloads 等位置，图片能用相册／文件管理器打开。
- [ ] 16:9 PNG 为 1920×1080，4:3 为 1440×1080；与完整预览一致且无操作轮廓。
- [ ] 独立轨道可导出透明 PNG 和 SVG，包含选择的选段、裁切和图标。
- [ ] 导出／导入文字预设和滤镜预设，上传字体、贴图、蒙版随文件恢复；坏文件不覆盖原数据。
- [ ] 每种导出都测试一次取消，再次保存能成功，取消不丢作品。
- [ ] 编辑后等“已保存到本机”，正常返回退出并重开，文字、素材、预设及两个画幅恢复。
- [ ] 编辑时退后台、切回、旋转手机，内容不丢；手机正常重启后再打开仍保留。
- [ ] 返回键先关闭弹窗，编辑页返回先保存；模拟存储不足时保留页面并提示重试。

反馈问题时请说明：Android／ColorOS 版本、发生问题的步骤、涉及功能、是否能重复出现；可以附错误页面或录屏。无需提供密码或密钥。
