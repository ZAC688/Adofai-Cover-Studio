## A13：实际重启电脑后的恢复

- [ ] 从完整包双击 `ADOFAI-Cover-Studio.exe`，确认直接打开独立桌面窗口，不启动浏览器。
- [ ] 上传底图和轨道，修改两行标题、颜色、字号、位置及光效。
- [ ] 执行去背景，在修正区完成至少一次擦除和一次保留，返回构图。
- [ ] 分别修改 16:9 和 4:3 下的位置或字号，保存两张导出图作为对照。
- [ ] 等顶部显示“已保存到本机”，记录作品名称及当前画幅。
- [ ] 使用 Windows 的正常重启操作重启电脑。
- [ ] 重启后再次双击启动程序，不重新选择源图片或重新识别。
- [ ] 两行文字、素材、颜色、光效、两种画幅布局以及画笔结果均恢复。
- [ ] 再次导出两种尺寸，检查与重启前构图一致。

记录：Windows 版本、程序版本、检查日期、实际结果与异常。

## A14：操作系统断网的完整流程

- [ ] 在程序退出状态下断开该电脑的网络连接。
- [ ] 首次从交付包启动，确认不需要在线安装资源或登录。
- [ ] 上传图片、识别、取消后重试、画笔修正、改标题、切换画幅、保存、导出。
- [ ] 关闭桌面窗口，重新从 EXE 打开，确认作品恢复。
- [ ] 使用“退出程序”，确认保存后正常退出；再次启动能继续编辑。

自动化中的外部请求拦截和模型禁网测试已经通过，但不以此代替本项真实断网操作记录。

## A15：第二台或干净 Windows 电脑

- [ ] 将 ZIP 复制到另一台符合目标环境的 Windows x64 电脑，完整解压。
- [ ] 不安装开发工具，不复制开发目录或用户缓存，不安装浏览器或 WebView2，直接启动 EXE。
- [ ] 准备独立的验收图片；分发包不携带开发者的私人截图。
- [ ] 断网启动，并执行上传、识别、修正、两行标题、双画幅、保存与 PNG 导出。
- [ ] 验证关闭桌面窗口、退出程序、重启电脑后的恢复。
- [ ] 确认数据写入该电脑当前 Windows 用户的本地应用数据目录，不引用开发者路径。
- [ ] 记录系统版本、程序版本、测试日期和结果；未测试的平台版本不宣称已通过。
