# 六项升级执行记录

按用户要求依次处理，每项测试通过后独立提交，最终执行全量测试。

## 1. 黑白极简主题

- 界面统一为黑、白、灰，去除彩色装饰，保留原布局及所有功能。
- 未对画布设置灰度滤镜，作品颜色保持独立。
- 新增实际 Edge 测试，检查界面背景、文字及边框为中性色，同时验证彩色文字仍正常渲染。
- 验证：前端 6 项单元测试、主题与原编辑／导出 7 项 Edge 测试通过；类型检查、代码检查、生产构建通过。
- 证据：`artifacts/upgrade/01-theme/tests.xml` 与 `editor.png`。

## 2. 可叠加光效

- 文字与轨道共用外发光、内发光、多尺度 Bloom、发光描边、渐变填充、斜面高光和水平模糊模块，分别开关并独立保存。
- 从透明度蒙版生成效果，远到近绘制柔光／辉光／描边，再绘制清晰主体及受蒙版约束的内部高光。渐变属于主体填充，其他光效提供 Screen／Add。
- 支持颜色、强度、半径、描边宽度、渐变／高光方向；水平模糊采用仅 X 轴的滤波。
- 保留旧作品与发光强度兼容；修复旧强度为零时新外发光无法有效启用的默认值问题。
- 验证：9 项前端单元测试、33 项后端与 Edge 测试通过；类型检查、代码检查及构建通过。
- 实际像素测试覆盖各模块独立开关、主体清晰度、Screen／Add 差异、渐变方向、文字／轨道独立保存和预览／导出一致性。
- 证据：`artifacts/upgrade/02-effects/tests.xml`。

## 3. 字体选择和上传

- 内置完整的 Noto Sans SC、Noto Serif SC、Inter、Noto Serif，固定上游版本与 SHA-256，随本地界面打包 OFL 许可，不依赖在线字体服务。
- 支持经实际字体表校验的 TTF、OTF、WOFF、WOFF2 上传；字体单文件最大 50 MB，图片仍为 10 MB。
- 上传字体本体存入用户数据目录，作品保存字体 ID；旧作品默认保持原系统字体。渲染前等待指定字体就绪，选中提示与导出使用同一字体。
- 构建遇到旧 EXE 被占用后，改用独立输出目录；未结束用户当前程序。打包测试自动使用最近一次成功构建的项目内目录。
- 验证：9 项前端单元测试、39 项后端／Edge 测试以及 3 项实际冻结 EXE 字体测试通过，包含 WOFF2 解码、中文／英文真实字形差异、刷新恢复、损坏字体拒绝和导出一致性。
- 证据：`artifacts/upgrade/03-fonts/tests.xml`、`package-tests.xml`、字体源清单 `frontend/public/fonts/manifest.json`。

## 4. 贴合轨道的选中轮廓

- 使用轨道主体的透明度边界绘制选中线，保留凹形、多个独立区域和内部孔洞，不绘制素材矩形选框。
- 缩放手柄独立显示，主体几何不计入外发光、Bloom 等光效。
- 鼠标命中同样依据主体透明度，透明留白不能抓取轨道；原拖动回归改为拖真实可见像素，保留原有位置与画幅恢复断言。
- 验证：12 项前端单元测试、8 项 Edge 轮廓／编辑／导出测试通过；类型检查、代码检查及构建通过。
- 证据：`artifacts/upgrade/04-selection/tests.xml`、`outline.png`。

## 5. 文字与轨道旋转

- 增加角度输入／滑块及可拖动旋转手柄，两种画幅独立保存角度。
- 轨道以可见主体中心旋转，文字以文字框中心旋转；光效、轮廓、透明度命中和导出采用相同变换。
- 旋转后缩放围绕同一中心，保留旧作品零角度行为。
- 有效测试发现输入框失焦会中途结束拖动历史分组，已修复为先结束字段编辑，再开始整个画布手势；一次撤销恢复整次旋转。
- 验证：14 项前端单元测试、51 项后端／Edge 测试通过；类型检查、代码检查及构建通过。包括真实像素旋转、轮廓及命中对齐、画幅记忆、刷新恢复、导出一致和手柄撤销。
- 证据：`artifacts/upgrade/05-rotation/tests.xml`。

## 6. 各最多五个标题和轨道、混合排序

- 增加标题／轨道添加、删除和计数上限；底图锁定最底层，其他对象可混合拖动排序，并提供上下移动按钮。
- 渲染与鼠标命中都采用同一层序，每个标题独立字体和效果，每个轨道独立图片、调色、效果、识别与画笔结果；位置、缩放、字号及旋转分别在两种画幅中记忆。
- 兼容原有两个标题／单轨道作品，保留原遮挡顺序。删除不立即删除原始资源，撤销可完整恢复；全部删除后可从上传入口重新创建轨道。
- 满容量时对象面板独立滚动，画布和导出入口保持在窗口内；已检查真实界面截图。
- 原旋转测试将新增布局容器误当作坐标对象的问题已修正：明确检查原四个坐标对象，零角度兼容断言扩大到全部原对象；新增测试另检查所有额外对象角度和布局。
- 验证：17 项前端单元测试、80 项完整后端／Edge 回归测试，以及最后调整后的 8 项针对性 Edge 测试均通过；10 项实际冻结 EXE 测试全部通过。未删除或跳过任何测试。
- 更新 PRD v0.4、使用说明和实机验收表；构建独立的 0.2.0 Windows 包，不结束用户旧进程。
- 证据：`artifacts/upgrade/06-objects/tests.xml`、`final-targeted-tests.xml`、`package-tests.xml`、`five-each.png`、`mixed-layers.png`。
