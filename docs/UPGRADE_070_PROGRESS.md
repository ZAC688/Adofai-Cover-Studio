## 2. 独立桌面与打包

默认入口改为 Qt WebEngine 独立窗口，随包提供 PySide6 6.12.0／Qt WebEngine 6.140.0，不依赖已安装的 Edge、Chrome 或 WebView2。保留原本机服务与 SQLite 路径；关闭窗口或点击退出前提交最后编辑，保存失败保留窗口与内容。使用原生文件保存对话框，禁止页面访问外网／任意本机文件；已有窗口可再次激活。

构建阶段固定依赖并校验 PyPI SHA-256，运行时不下载组件。随包收录完整 GNU 许可证文本和与引擎版本一致的 127 份官方第三方许可／版权说明。目标平台 Windows 10（1809 或更高）／11 x64，平台依据为 Qt 官方支持表；目前实际测试主机仍是 Windows 11。

首次冻结包测试发现开发工具链 PATH 中的 ICU 78 被错误收集，导致 QtCore 加载失败。已隔离打包进程 PATH，使 Qt 使用 Windows 自带 ICU，并增加包中禁止混入外来 ICU DLL 的回归断言。未删除测试或降低标准。

测试：类型检查、lint、前端 39 项与生产构建通过；桌面／轨道集成及 URL 规则 22 项通过（59.45 秒），独立冻结 EXE 2 项通过（8.67 秒）。真实内置引擎验证包括关闭前最后输入保存、重开恢复、保存失败保持窗口、退出按钮退出、3D／滤镜实际像素、轨道预览及独立 PNG 下载、最终 PNG 与画布逐像素一致。测试窗口位于屏幕外，不影响用户桌面。

已保留集成工具的独立高分辨率轨道 PNG 导出，并补充“普通额外轨道不得继承第一轨道源谱面参数”的单元回归。验证用 EXE 位于 dist/0.7.0-validation；最终版本与说明书将在下一阶段重新打包。
