# 静态轨道选段与缩略图试验

在四份谱面的静态验证基础上增加：起止砖块选择、裁切、自动适配、默认颜色、兔子／乌龟／旋转图标和高分辨率缩略图。继续作为离线独立试验，不改动已发行编辑器。

## 1. 选段、裁切与适配

已实现包含两端的砖块编号选择，保留原谱的坐标与边界端口；支持单块选择。裁切使用世界坐标矩形，真正裁掉框外内容；按指定画布尺寸等比居中，保留留白，不拉伸。尺寸与内存上限、非法编号及无效裁切均有明确校验。

新增 18 项测试及原 42 项回归共 60 项通过，0 失败／跳过。覆盖含端点选段、裁切遮罩、画面外轨道排除、单块导出、居中等比适配和错误参数保护。证据：`artifacts/static-track-editor/01-selection-tests.xml`。

## 2. 默认轨道色与图标

读取 settings.trackColor（支持 RGB／RGBA），使用统一平面填充，不复刻 Glow／Neon 等材质和色彩动画。按完整谱面的累计 BPM 计算加速兔子、减速乌龟；等速不显示图标，同块多个变速先合并净变化，选段不重置 BPM。旋转图标随 Twirl 状态交替方向，所有图标可沿砖块方向旋转或保持直立，多图标自动分开放置。图标为自绘矢量，不是游戏原版素材。

新增 20 项图标测试，连同选段、原验证及 4 份真实主谱共 90 项通过，0 失败／跳过；图标测试单独重跑 20 项通过。已查看实际 PNG 的兔子、乌龟和带箭头旋转图标。证据：`artifacts/static-track-editor/02-icons-tests.xml`、`icons-demo-preview.png`。

## 3. 离线交互页面与高分辨率缩略图

生成独立、自包含的 HTML，包含四组主谱的矢量砖块、轨道色和共享图标模板，打开后无需服务器或网络。页面支持：

- 输入包含两端的起止编号；在预览上点选起点／终点，在整图上点击定位附近轨道，或恢复示例选段／整条轨道。
- 在预览上拖矩形裁切，重置裁切，等比居中自动适配和调整留白；改变编号范围会清除旧裁切框。
- 16:9、4:3、紧贴内容；长边 1920、2560、3840、4096 像素。
- 显示／隐藏图标、随砖块方向旋转／保持直立、可选砖块编号。
- 直接重新绘制矢量几何，导出指定尺寸的透明 PNG 和带裁切路径的 SVG，不放大预览图；生成期间锁定输入，避免导出文件与当前设置错位。
- 每谱面的选段、裁切和导出设置保存在当前浏览器，刷新和切换谱面后恢复。采用按源文件哈希隔离的本地设置，不保存谱面媒体资源。

已生成四份 **3840×2160** 示例 PNG、SVG 和 JSON，保留原文件。HTML 约 3.8 MB，全部数据内嵌。PNG/SVG/浏览器共用同一套砖块几何和图标模板，浏览器预览与下载分别绘制。

本阶段新增 10 项页面／导出测试和 5 项真实谱面验收，15 项通过。最终重跑**全部 105 项实验相关测试，0 失败、0 错误、0 跳过、无警告**，28.37 秒。其中包含真实 Edge 浏览器的离线访问、点击选砖、框选裁切、浏览器刷新、分谱面恢复、错误输入保护、4K PNG 下载、SVG 内容、4:3／紧贴内容和图标方向验证。已查看实际界面截图和四图样张。

证据：`artifacts/static-track-editor/03-editor-tests.xml`、`all-tests.xml`、`workspace.png`、`samples-overview.png`。生产编辑器和分发包未变更，本轮未重跑完整应用／冻结包测试。

## 使用

1. 在项目根目录打开 `artifacts/static-track-editor/index.html`，或在浏览器中打开该文件。这是本轮新增的选段页面，与上一轮只读总览页面不同。
2. 选择谱面，输入起止砖块编号；编号从 0 开始。可在整图上点击定位，也可切换“点选起点／终点”后点击预览中的砖块。
3. 需要局部画面时选择“框选裁切”，在预览中拖框。选择画幅、导出尺寸及留白，自动等比居中；使用“重置裁切”恢复完整选段。
4. 点击右上角导出透明 PNG 或 SVG。4K 默认输出 3840×2160（16:9），4:3 为 3840×2880；选择“紧贴内容”时长边保持指定像素。

四图样张：`artifacts/static-track-editor/samples-overview.png`。每份主谱的子目录包含 `thumbnail-4k.png`、`thumbnail-4k.svg`、深色阅读版与导出元数据。

重现生成与全部相关测试：

```powershell
.\.venv\Scripts\python.exe -m experiments.static_track_editor
.\.venv\Scripts\python.exe -m pytest tests/experiments experiments/test_static_track_samples.py experiments/test_static_track_editor_samples.py -q --junitxml=artifacts/static-track-editor/all-tests.xml
```

已知差异仍沿用首轮报告：仅基础方向与 PositionTrack 平移试算；Heaven’s Gateway 的静态缩放，以及它与 Crystallized 的粘性轨道语义尚未还原。读取默认颜色，不还原色彩动画与 Glow／Neon 材质；兔子、乌龟与旋转图标为自绘矢量示意。未宣称与游戏原版像素一致，尚未接入封面编辑器。
