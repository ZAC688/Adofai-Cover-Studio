# ADOFAI 封面制作器使用说明

## 启动

1. 将完整的 Windows 压缩包解压到电脑目录。
2. 双击文件夹内的 `ADOFAI-Cover-Studio.exe`。
3. 程序直接打开独立桌面窗口，无需登录、安装浏览器或联网。EXE、窗口和任务栏使用界面左上角的 A 字 Logo。

请保留 EXE 旁边完整的 `_internal` 文件夹，不要只复制单独的 EXE。适用于 Windows 10（1809 或更高）／11 的 64 位系统。运行组件已包含在程序包中，无需安装浏览器、WebView2、Python、Node.js 或开发工具。

当前实际测试环境是 Windows 11 x64（系统内部版本 22621），内置 Qt 6.12／WebEngine 6.140。Windows 10、第二台电脑与真实系统重启仍需按实机清单检查，不能用本机测试代替。

更新到 0.8.1 前，先在旧版窗口点击“退出程序”，等待退出，再打开新包。0.6.0 及更早版本仅关闭浏览器仍可能保留旧版服务，须先点击旧版“退出程序”。0.7.0 起关闭桌面窗口会先保存并结束服务。更新保留 `%LOCALAPPDATA%\AdofaiThumbnailGenerator` 中的数据，建议退出后先备份整个目录。

## 制作封面

- 使用顶部“上传底图”“上传轨道”添加素材，支持 PNG、JPEG；每个原始文件不超过 10 MB（10,000,000 字节）。左侧较长的对象列表可独立滚动。
- 初始提供两个标题和一个轨道占位。点击“添加标题”或“添加轨道”创建对象，标题、轨道分别最多 5 个；选中后可“删除对象”，支持撤销恢复。
- 在“作品对象”拖动行调整混合顺序，列表上方覆盖下方；也可用上下箭头移动。底图锁定在最底层。
- 选中标题，在右侧填写文字，修改颜色、字号、位置和发光强度。
- 字体可选系统字体、思源风格的 Noto Sans SC／Noto Serif SC 中文字体，以及 Inter／Noto Serif 英文字体；内置字体随包离线可用。也可上传 TTF／OTF／WOFF／WOFF2，单文件不超过 50 MB。上传字体保存于本机，分发自己制作的素材前应具备对应字体的使用权。
- 选择底图或轨道后，在画布里拖动位置；轨道右下角可以等比例缩放，也可输入数值。
- 轨道可以保留原色，或改成指定颜色并调整发光强度。
- 文字和轨道可输入旋转角度或拖动上方圆形手柄。将鼠标移入画布可见变换手柄；移动／缩放／旋转过程中显示主体轮廓，松手后隐藏，编辑参数时不遮挡预览。轨道轮廓忽略辉光，透明留白无法拖动轨道。
- 展开“光效模块”，分别开关和叠加外发光、内发光、多尺度 Bloom、发光描边、渐变填充、斜面高光与水平模糊。每个对象单独设置颜色、强度、范围、描边宽度及方向；光照模块可选择 Screen／Add。渐变改变主体填充，主体在外部柔光之后绘制以保留清晰字形。
- 基础发光设置及每个光效参数可分别折叠；折叠后光效继续生效，开关和已有参数保留。
- 在某个光效内打开“跟随渐变填充”，该模块会使用渐变填充的方向和两端颜色；关闭填充本身仍可跟随，取消跟随则恢复模块自身颜色。
- 文字、轨道和贴纸可独立添加阴影，调整颜色、不透明度、模糊、方向和距离。
- 点击 16:9／4:3 切换画布，两种比例分别记住排版；文字内容和颜色等效果共享。
- 每个轨道分别保存图片、调色、光效、识别和画笔结果；先在对象栏选中目标，再上传或替换。
- 可用顶部按钮撤销／重做；文字输入框使用正常的文字撤销快捷键。
- 选中标题、轨道或贴纸后按 Delete 可以删除并撤销；编辑文字、数值或操作弹窗时不会触发对象删除，底图保持锁定。
- 顶部“信息”可以离线查看作者 ZAC688、当前版本、更新日志及本说明，按 Esc 关闭。

## 从谱面生成轨道

1. 点击顶部“从谱面生成”，选择本机 `.adofai` 文件。单文件最大 10 MB，最多 20000 段；不需要音乐、背景图片或装饰素材。
2. 输入起止砖块编号，编号从 0 开始且包含两端；也可在整图上点击定位，再用“点选起点／终点”选择预览中的砖块。
3. 默认“金黄色石砖”外观，可切换“谱面配色”。兔子表示加速，乌龟表示减速，旋转图标区分方向；可隐藏图标、关闭随砖块旋转或显示编号。
4. 需要局部画面时使用“框选裁切”，拖出矩形；“重置裁切”恢复完整选段。改变编号范围会清除旧裁切框。画面等比居中自动适配，可调整留白。
5. 可选 16:9、4:3 或“紧贴内容”，导出长边为 1920／2560／3840／4096 像素；16:9 的 3840 为 3840×2160，4:3 为 3840×2880。图像从矢量几何重新绘制，保留透明背景。
6. 点击“生成并预览”查看实际生成图片。可“返回调整”、“导出轨道 PNG”单独保存高分辨率素材，或“应用到封面”。选段窗口还可导出 SVG。
7. 应用后成为轨道对象，优先填入空轨道位置，仍受轨道最多 5 个的限制；已有轨道不被新生成对象覆盖。可以继续旋转、缩放、添加光效／阴影／滤镜及调整图层顺序。
8. 在作品对象的“⋯”菜单选择“编辑谱面选段”可再次修改。已应用的源谱面、选段、外观、裁切及图标参数保存在本机，不依赖原谱面路径；再编辑保留已有排版和效果。用“替换图片”改为普通图片会清除生成关联，可撤销恢复。

金黄色石砖按官方参考图细化直角／斜角拼接、圆头、细接缝、明暗边、石纹凹点及裂纹；兔子采用连续轮廓，旋转图标区分螺旋与红／蓝箭头的层次。预览、PNG 和 SVG 使用相同的几何与细节。

生成窗口还会显示谱面填写的音乐名称和音乐作者；可分别勾选“生成音乐名称标题”和“生成音乐作者标题”，默认均关闭。勾选后，在“应用到封面”时新增独立白色、零发光标题，可以继续修改字体、字号、位置和效果。读取的是音乐作者，不是制谱人，谱面中的颜色／字号标签会清理为纯文字；未填写的字段说明缺失并禁用相应勾选项。

这些标题计入最多五个标题；名额不足时提示并禁用应用，减少勾选或先清理不需要的标题后可继续，已有文案和对象不被覆盖。生成预览期间不添加标题；再次编辑轨道时两个选项仍默认关闭，避免重复生成。一次撤销可以同时还原本次轨道及新增标题。

取消或关闭生成窗口不会修改作品；需点击“应用到封面”才写入当前作品。高分辨率轨道素材与最终封面分开导出，最终封面仍为下文规定的 1080 高画布尺寸。

当前只生成静态轨道，颜色、纹理和图标按参考图重绘，不承诺与游戏原版逐像素一致。只应用基础方向和 PositionTrack 静态位移，不还原轨道动画、镜头、装饰、特效及色彩动画；静态缩放和粘性轨道仍未完整还原，包含这类设置的谱面可能与游戏布局不同。

## 文字预设

1. 在作品对象中选中标题，切换右侧“滤镜”，展开“文字预设”。普通 2D 和 3D 文字均可保存，没有滤镜也可以使用。
2. 填写预设名称，点击“保存为文字预设”。保存字体、两种已建立画幅的字号、文字颜色、发光、各光效模块、阴影、全部 3D 配置和当前标题的滤镜，包括顺序、开关、局部范围、贴图及蒙版。
3. 选择本机文字预设，点击“应用文字预设”。当前文案、位置和对象旋转角度保持原样，样式、字号和该标题的滤镜被替换；其他对象保持原样，可一次撤销／重做。3D 配置内部的三轴朝向属于样式，会随预设恢复。
4. “导出文字预设”保存自包含 JSON 文件，“导入文字预设”可在本机或另一份数据目录使用，单文件上限 100 MB。上传字体的实际文件、滤镜贴图和蒙版随预设携带，内置字体由程序提供。反复应用同一上传字体会复用已保存的字体。
5. 预设保存在本机，退出再打开仍可选择。损坏文件或资源校验失败会提示错误，原作品和已保存预设保留；保存失败保留预设名称，可重试。

原有“滤镜预设”功能和文件继续可用，支持标题、轨道、贴纸与整画布；两类预设各自保存和选择。

## 3D 文字

选中标题，点击“一键生成 3D 文字”。原文字、字体和标题名额沿用，点击“切回普通文字”恢复普通模式，3D 配置会保留。

- 展开“3D 配置”，调整厚度、倒角、三轴旋转和透视。厚度、倒角以字号百分比计算；透视为 0 时使用正交视图。
- “文字颜色”控制正面，“3D侧面颜色”控制侧面。主光可调整方向、高度、强度，环境光控制整体亮度；“恢复默认3D配置”可重置这些配置。
- 支持现有预设及 TTF／OTF／WOFF／WOFF2 上传字体。英文字体缺少中文时使用本机黑体回退。
- 可继续添加光效、阴影和滤镜，或拖动、旋转、排序、撤销；两种画幅的预览与导出均使用真实 3D 投影，最终输出静态 PNG。

## 预设贴纸

1. 点击左侧“选择贴纸”，按原文件夹层级浏览全部 253 份预设。
   “TUF / 新等级”中 P 开头的贴纸放在最前，crazy 放在最后，各组内部仍按名称自然排序，例如 P2 在 P10 之前；其他分类及“全部素材”保持名称自然排序。
2. 点击素材；GIF 可以用滑块选择其中一帧，预览的是最终静态帧。
3. 点击“添加贴纸”，对象栏显示“贴纸”和素材名。相同素材可重复添加，贴纸不设数量上限，也不占用标题／轨道的 5 个名额。
4. 拖动位置、缩放手柄，或输入宽度／高度、缩放及角度；默认保持原比例，可加阴影、混合排序、删除和撤销恢复。

贴纸选定的实际图片会保存到作品数据目录。最终仍导出静态 PNG，不包含动画；分类选择器不提供编辑或管理素材目录的功能。

字体预设另含 Bebas Neue、Russo One 和 Space Mono；Space Mono 的常规、斜体、粗体、粗斜体分别可选，均随程序离线提供。Clash Grotesk、Tanker 不启用或分发。

## 图片融合

1. 上传尚未去背景的轨道截图，在对象行的“⋯”菜单选择“融合”，或点击右侧“融合图片”。已经开启去背景时，先关闭该开关。
2. 窗口显示完整构图和渐变蒙版。白色区域保留图片，透明区域淡出，两者之间平滑过渡。
3. 调整过渡位置、宽度和角度；勾选“反转渐变”可交换保留与淡出的方向。位置和宽度相对于原图在指定方向的跨度计算，图片旋转时蒙版随图片旋转。
4. 点击“应用融合”写入作品；“取消”不改变原作品。保存失败会保留当前草稿，可重试。
5. 重新打开可继续修改；“重置融合”恢复位置 50%、宽度 50%、角度 0° 和正向渐变，应用后生效。关闭“启用融合”会保留参数但暂停效果。应用后可通过编辑器撤销／重做。

原图和自动识别修正结果均保留。去背景开启期间暂停原图融合，关闭后可继续使用已有融合设置；替换轨道图片会清空旧图片对应的融合设置。

旧作品的柔边画笔、混合模式及不透明度按原样显示。打开新窗口后，只有调整参数并应用，才会替换为渐变蒙版；直接关闭或取消不会改变旧效果。

## 去背景和修正

1. 选中轨道，展开“去背景与轨道修正”。
2. 打开“自动去除背景”，等待本机处理，过程中可取消。
3. 自动完成后点击“修正轨道”。
4. 用擦除画笔清理背景，用保留画笔恢复误删的原始像素；可以调整画笔、缩放、平移和对照原图。
5. 每笔完成后保存修正；如果保存失败，保留当前草稿并点击重试，保存成功后返回构图。

当前优先处理纯色和暗色低对比纹理背景，保留轨道轮廓、内部和图标。用户 `test_2` 的 9 张截图已使用独立确认标注逐张验证，自动结果 IoU 均达到 90%。复杂背景保留旧候选能力，可用画笔修正，不承诺复杂背景质量达标。

关闭去背景开关可以显示原图；再次打开复用修正结果。重新识别会提示是否替换已有修正，取消提示不会覆盖结果。

## 保存与导出

右侧“滤镜”栏目按当前选中的对象显示和管理滤镜；“管理范围”可切到整张画布。可添加全部 38 种滤镜，逐个开关、调参、排序或删除。进入栏目和切换对象时，已有滤镜详情默认折叠，点击名称展开；新添加的滤镜会展开。列表整体也可折叠。“恢复默认参数”仅重置参数，保留开关、目标及局部范围，支持撤销。多个对象共用的滤镜可从对应目标访问。

在“滤镜预设”中填写名称并“保存为滤镜预设”，本机保存当前目标的整套滤镜、参数、开关、顺序和两种画幅的局部范围。选择本机预设后可应用或导出 `.adofai-filters.json`，也能导入预设文件；贴图和范围蒙版包含在文件内，可在另一台电脑导入。文件最大 100 MB。应用会替换当前目标的滤镜，可撤销；原来共用滤镜的其他对象保留效果。导入和保存预设本身不会改变画面。

滑块使用常用范围，可点击“精细调节”缩小到当前值附近，再次点击回到常用范围。需要更大或更小的值时直接输入数字，已有值不会因常用范围而改变。局部区域可框选或柔边涂抹，确认后写入作品，取消不改变原设置；两种画幅分别保存范围，导出使用同样处理。

光效使用本地后台线程计算，连续调节时显示中间预览并优先处理最新参数，最终预览和导出均保持完整分辨率。

0.8.1 修复大范围光效导致移动、输入和调参预览延迟的问题：绘制型光效允许使用 GPU，未变动的光效像素会复用，缓存最多保留 96 MiB。界面优先显示输入变化，随后更新较重的预览，并减少重复重建画布。首次加载或修改光效本身仍需计算，实际速度取决于素材、效果和电脑配置；作品、预设和导出分辨率保持原样。

所有预设贴纸视图按名称自然升序排列，例如 2 在 10 之前。新建标题和轨道的默认发光强度为 0，可按需开启光效；旧作品保留原设置。

调色板连续选色时，色块即时响应；画布在短暂停顿（约 120 毫秒）或确认颜色时更新。离开颜色框、切换对象／画幅、撤销或导出时会立即应用最后一次选色；预览与最终导出保持完整分辨率。

- 顶部“已保存到本机”表示当前版本已成功写入本地数据目录；“正在保存”表示仍有提交未完成。
- 保存失败时，当前编辑内容仍在页面中，可重试保存。另一个窗口修改同一作品时，程序会提示冲突，不会静默覆盖。
- 点击“导出图片”，查看最终预览、填写文件名，再点击“导出到电脑”。
- 16:9 输出 1920×1080 PNG，4:3 输出 1440×1080 PNG；编辑边框、操作手柄和透明棋盘格不会出现在导出图片中。
- 点击导出后，在系统保存对话框中选择目录和文件名；取消对话框不会修改作品。

作品数据保存在当前 Windows 用户本地应用数据目录下的 `AdofaiThumbnailGenerator` 文件夹，通常可通过资源管理器地址栏输入 `%LOCALAPPDATA%\AdofaiThumbnailGenerator` 打开。该目录包含素材、蒙版、上传字体、源谱面与生成参数、滤镜预设、文字预设和作品数据库，与程序目录分开保存。删除对象不立即删除素材文件，方便撤销；不依赖原始上传路径。

更换程序目录不需要重新上传图片。需要手动备份时，先退出程序，再复制整个数据文件夹。

## 退出和重新打开

关闭桌面窗口的“×”或点击“退出程序”，都会先提交最后的编辑内容，再关闭窗口和本机服务。保存失败会保留窗口与内容，按提示重试成功后再关闭。

再次双击 EXE 会恢复上次作品；如果已有本程序窗口，则激活现有窗口。更换程序目录不会删除作品。

## 轨道识别范围

轨道识别适用于纯色或暗色规则纹理背景。复杂背景提供候选结果，必要时使用画笔修正保留范围。
