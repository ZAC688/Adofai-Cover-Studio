# 0.3.0 五项升级记录

按用户确认的顺序逐项实现、添加有效测试，通过后独立 Git 提交。所有既有测试和识别质量门槛保留。

## 1. 光效参数折叠

- 基础发光设置和每个启用的光效参数都可以单独折叠，开关保留可见；折叠不会改变作品或关闭效果。
- 重新展开保留强度、半径和颜色；关闭后再开启仍保留参数，并自动展开以便编辑。
- 验证：17 项前端单元测试及 5 项真实 Edge 光效测试通过，类型检查、代码检查、构建通过。
- 新增文字／轨道两组测试，验证折叠前后作品数据及实际像素完全相同、导出一致、折叠后可关闭模块且重开参数不丢失。
- 证据：`artifacts/upgrade-03/01-collapse/tests.xml`。

## 2. 光效跟随渐变填充

- 六个光照模块独立选择跟随渐变填充的方向及两端颜色；关闭填充本身仍读取保存的渐变设置，取消跟随后恢复模块原有颜色。
- 共用主体坐标下的渐变范围；文字与轨道各自保存，旧光效默认不跟随。
- 验证：18 项前端单元测试、15 项后端及真实 Edge 测试通过，类型检查、代码检查及构建通过。
- 对全部六种光效逐一检查真实像素变化、方向变化及取消跟随后的像素恢复；另验证轨道刷新恢复和导出逐像素一致。
- 证据：`artifacts/upgrade-03/02-gradient/tests.xml`。

## 3. 文字和图形阴影

- 文字与每条轨道独立开关阴影，支持颜色、不透明度、模糊、方向和距离，参数可折叠；旧作品默认没有阴影。
- 阴影从主体透明度生成，先于光效和清晰主体绘制，随对象一起旋转；不把透明留白变成矩形阴影。
- 验证：19 项前端单元测试、66 项后端／Edge 回归和 3 项最终阴影测试通过；类型检查、代码检查、构建通过。
- 检查真实硬边／柔边像素、精确方向与孔洞、独立保存、旋转、刷新恢复及导出逐像素一致。初次新测试导入错误已修正后完整重跑。
- 证据：`artifacts/upgrade-03/03-shadow/tests.xml`、`alpha-tests.xml`。

## 4. 分类预设贴纸和 GIF 选帧

- 使用用户 `Logos` 中全部 253 份素材（245 PNG、8 GIF），完整保留文件夹层级；GIF 逐帧预览并选定静态帧。
- 添加后将实际 PNG 复制到作品数据目录，作为独立“贴纸”对象，支持重复添加、无数量上限、移动、尺寸、旋转、轮廓命中、阴影、排序及删除／撤销。
- 标题和轨道仍分别最多 5 个，贴纸不占用其名额；两种画幅独立保存位置、尺寸和旋转。
- 验证：20 项前端单元测试、72 项后端／真实 Edge 测试通过；类型检查、代码检查、构建通过。全部 GIF 的最后一帧与原素材逐像素比较，100 份贴纸数据恢复、12 次界面重复添加和静态导出均通过。
- 拖动测试记录确认原工具在滚动目标前误抓旁边标题，改为先抓住源对象再滚动到目标的真实手势，保留原排序断言后通过。
- 证据：`artifacts/upgrade-03/04-stickers/tests.xml`、`editor.png`。

## 5. 柔边画笔和图片融合

- 轨道对象行“⋯”菜单和属性栏均提供融合入口，面向未去背景原图；窗口同时显示整幅构图预览和原图坐标画笔区。
- 支持柔边擦除／还原、大小、柔和度、力度、画笔撤销重做、原图对照和重置；六种混合模式及整体透明度可与画笔组合。
- 融合效果按完整对象统一混合，阴影和光效随主体一起处理；专用融合蒙版不覆盖自动识别和手工修正蒙版。去背景开启期间暂停融合，替换原图时清空对应旧融合。
- 取消不写作品，应用后统一进入构图撤销历史；保存失败保留草稿重试。旋转中心取原主体几何，不因局部擦除跳动；不对称选中框的手柄命中已同步修正。
- 验证：21 项前端单元测试、77 项后端／真实 Edge 回归、7 项最终融合／旋转测试和 16 项冻结 EXE 测试通过。包括连续透明像素、六种混合实际颜色、预览／PNG 逐像素一致、取消与失败重试、多轨道隔离及不对称蒙版下的真实命中和旋转撤销。
- 独立性测试曾在初始图片尚未自动保存时读取旧基线，已改为等待保存成功后建立基线，保留隔离断言重跑全部针对性测试通过。
- 完成 PRD v0.5、操作说明和验收清单，独立构建 `dist/0.3.0` 及对应 ZIP，校验 SHA-256 一致。用户新放入的根目录 `fonts` 压缩包保持原样，未纳入本轮提交或分发包。
- 证据：`artifacts/upgrade-03/05-fusion/tests.xml`、`final-targeted-tests.xml`、`package-tests.xml`、`window.png`、`editor.png`。
